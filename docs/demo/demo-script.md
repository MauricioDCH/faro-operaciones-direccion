# Guion del Demo Day

**Estado:** `planned`.

## Narrativa objetivo

1. Mostrar las fuentes sintéticas dispersas.
2. Ejecutar la ingesta y la validación de calidad.
3. Presentar una inconsistencia conocida y su evidencia.
4. Presentar una alerta de inventario o ventas y su cálculo determinístico.
5. Formular una pregunta empresarial priorizada.
6. Rastrear la respuesta hasta los registros de origen.
7. Mostrar los comandos reproducibles y el resultado actual de las pruebas.

## Contingencia

Preparar una ruta local con dependencias mínimas y fixtures sintéticos pregenerados. Toda integración simulada debe identificarse con claridad y nunca presentarse como implementada.
