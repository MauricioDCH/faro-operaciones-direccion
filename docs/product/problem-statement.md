# Definición del problema

**Estado:** documentado como hipótesis inicial; la validación de campo permanece en `planned`.

## Usuario objetivo

Propietario, administrador o coordinador de operaciones de una micro o pequeña empresa comercializadora o distribuidora de Medellín.

## Problema

La información operativa se encuentra distribuida entre hojas de cálculo, archivos CSV, facturas PDF y mensajes, pero no se integra, valida ni rastrea de forma consistente para respaldar decisiones oportunas.

## Consecuencias esperadas

- consolidación manual lenta;
- indicadores operativos inconsistentes;
- detección tardía o incompleta de anomalías;
- baja confianza en cifras que no muestran evidencia de origen.

## Regla de validación

Esta definición no debe generalizarse a todas las empresas locales hasta que entrevistas o flujos de trabajo observados aporten evidencia suficiente.
