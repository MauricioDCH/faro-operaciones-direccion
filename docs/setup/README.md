
# Instalación local

Faro admite Linux y Windows como plataformas objetivo. Los comandos Python son la interfaz canónica; `make` es una comodidad opcional en Linux.

- [Linux](linux.md)
- [Windows](windows.md)

La compatibilidad se considera validada únicamente cuando la matriz de CI y las pruebas locales correspondientes aprueban. El OCR requiere Tesseract con el idioma español. El procesamiento de PDF requiere además Poppler.
