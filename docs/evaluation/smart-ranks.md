# Notas sobre la evaluación de Smart Ranks

**Estado:** información pública registrada; la integración con OpenAI continúa sin confirmación.

## Dimensiones de evaluación descritas públicamente

- interacciones con IA y herramientas utilizadas;
- correcciones realizadas durante la resolución del problema;
- criterios satisfechos;
- reproducibilidad;
- revisión de la solución final.

## Aspectos no confirmados

- soporte directo para ChatGPT, ChatGPT Desktop o Codex;
- importación de prompts externos, historial de Git o telemetría de Codex;
- equivalencia de evaluación para una reproducción posterior en Claude.

No debe tratarse una suposición como una regla. Las respuestas escritas de los organizadores deben agregarse aquí con fecha, canal, texto exacto y ubicación de la evidencia.
